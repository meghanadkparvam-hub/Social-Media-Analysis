# Social Media Analysis Using Power BI

## Project Overview
This project analyzes social media user engagement using Microsoft Power BI.

## Project Objectives
- Analyze user distribution by country.
- Understand likes, comments and shares.
- Compare engagement by gender.
- Analyze video views and user professions.

## Tools Used
- Microsoft Power BI
- CSV Dataset
- GitHub

## Dataset Information
- Total Records: 200 users
- Total Columns: 11

## Dashboard Features
- Total Users
- Average Likes
- Average Comments
- Average Shares
- User Distribution by Country
- Likes by Gender
- Age-wise User Distribution
- Users by Profession
- Video Views Analysis

## Conclusion
This project provides insights into social media user engagement through interactive Power BI visualizations.
